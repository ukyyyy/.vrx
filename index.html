Header (40 B fixed) Magic bytes, version, chosen mode, KDF parameters, salt, and IV — all unencrypted, but authenticated.

Threat Model & GDPR
What Vault protects and what it doesn't

✓ Protects against: Cloud providers, backup services, lost USB drives, network attackers, and manipulated .vrx files.

✗ Does NOT protect against: compromised devices (malware, keyloggers), weak passwords, and loss of the key.

How secure is the password mode?

PBKDF2-SHA256 with 600,000 iterations (OWASP recommendation). With a random 12+ character password, brute-force attacks are practically impossible. For simple or dictionary-based passwords, even the strongest KDF cannot prevent attacks — use the random key generator in that case.

Verify this page's integrity

Download the HTML file and verify the SHA-256 hash against the release hash: shasum -a 256 virex-vault.html. Once verified, it can be run via file:// completely offline.

Short, unique, and recognizable. Stands for Virex + encrypted. It is identified by the magic bytes VRX\x02 and does not conflict with any other known format.
